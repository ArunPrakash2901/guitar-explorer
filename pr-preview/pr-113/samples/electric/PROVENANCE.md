# Clean electric guitar recordings

The source is FreePats [Electric Guitar FSBS (clean)](https://github.com/freepats/electric-guitar-FSBS-clean/tree/192cf0d9bf2c4ba6ead8e3524ba3f78818e4fe91), dated 2026-08-07. FreePats recorded a Fender electric guitar and processed the recordings through a clean amplifier and effects rack. The source uses CC0-1.0. The original license is included here.

The browser instrument uses thirteen bridge-pickup attacks with one take per pitch. The manifest records each source path and Git blob SHA, plus the encoded OGG size and SHA-256. The OGG files use mono Vorbis at 44.1 kHz, trimmed to 2.10 seconds with a 100 ms tail fade. The nearest pitch sample covers every supported standard-tuning fret within two semitones. The electric bank shares attacks across strings. Acoustic playback retains the separate Meta Steel Guitar bank with three recorded velocity layers.
