# Progression drum recordings

Kick, snare and closed hi-hat come from [Virtuosity Drums](https://versilian-studios.com/virtuosity-drums/) by Versilian Studios and Karoryfer Samples, performed by Austin McMahon. The [pinned source](https://github.com/sfzinstruments/virtuosity_drums/tree/9f04cf9a734527edfbb0a4eee1f674e45bbf71bc) uses CC0-1.0. The original license is in this directory.

The manifest records the three mid-microphone FLAC source paths and original Git blob IDs, and the sizes and SHA-256 hashes of the browser WAVs. The WAVs are mono 44.1 kHz signed 16-bit PCM. They remove leading silence, retain the first 0.23–0.44 seconds, and apply a short tail fade and peak adjustment.
